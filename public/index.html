Live portfolio via Moomoo OpenD

OpenD is a desktop app that talks to Moomoo over a local TCP port, so the deployed site cannot read your account. Use the Claude Code skills locally instead:

  1. Install and log in to Moomoo OpenD (default 127.0.0.1:11111).
  2. pip install moomoo-api
  3. Open this repo in Claude Code and ask: "Show my portfolio positions".

Rules: max 3 stocks · trailing stop the day you buy · no unplanned -10% holds · park idle cash in a money-market fund.
